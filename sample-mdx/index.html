🚀 Chào mừng bạn đến với MDX trong DoIt Studio!

MDX cho phép bạn kết hợp sự đơn giản của cú pháp Markdown với sức mạnh tương tác của các Component HTML/Astro.

✨ Tại sao nên dùng MDX?

  • Tốc độ sáng tạo: Viết nội dung bằng Markdown quen thuộc mà không cần tốn thời gian format HTML thủ công.
  • Tính linh hoạt: Nhúng linh hoạt bất kỳ component Astro/React/Vue nào ngay trong bài viết.
  • Hiệu năng cao: Mọi thứ được biên dịch sẵn thành Static HTML mượt mà.

📦 Thử nghiệm nhúng Component Astro vào MDX

Dưới đây là một ví dụ về Component Astro <Card /> được nhúng trực tiếp trong tệp .mdx này:

MDX Integration

Tính năng MDX Hoạt Động Hoàn Hảo

Bạn có thể tạo các Content Collection hoặc các trang tĩnh thông qua tệp .mdx trong thư mục src/pages/

💻 Ví dụ về Block Code

// Cấu hình astro.config.mjs với MDX
import { defineConfig } from 'astro/config';
import mdx from '@astrojs/mdx';

export default defineConfig({
  integrations: [mdx()],
});

Mẹo: Bạn có thể tạo thêm nhiều trang MDX mới đơn giản bằng cách tạo file .mdx bất kỳ inside src/pages/!
